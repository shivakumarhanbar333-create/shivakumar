Module 1: HTML Basics

In this session, we are learning how to structure a webpage using semantic HTML5 elements.

What is Semantic HTML?

Semantic tags describe their meaning to both the browser and the developer (e.g., <header>, <footer>).

Why use Semantic HTML?

It improves code readability, helps SEO, and makes webpages accessible for screen readers.
